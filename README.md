# ExifReader

一个纯客户端的 EXIF 读取与相框合成工具，无需后端，图片数据完全在本地处理，绝不上传服务器。

**[在线使用 →](https://shawbbb.github.io/Exifreader)**

---

## ✨ 功能特性

### 📷 EXIF 信息读取
- 拖拽或点击选择图片，支持 JPEG / HEIC / TIFF 等含 Exif 的格式
- 自动提取并展示：**机型、镜头、光圈、快门速度、ISO、焦距、拍摄日期、GPS 位置**
- 支持原始 EXIF 全字段查看（可展开折叠，支持搜索）

### 🌍 GPS 反向解析
- 自动将照片中的经纬度解析为可读的地名
- 优先使用 BigDataCloud API，失败时自动降级至 OpenStreetMap Nominatim
- 中国地址智能格式化（省 + 区/县）

### 📝 信息文本生成
- **详细格式**：逐行展示 `字段名：值`，适合摄影笔记
- **简约格式**：精简单行输出，适合社交媒体配文
- 支持拖拽调整字段显示顺序，支持单独开关每个字段
- 一键复制到剪贴板

### 🖼️ 相框合成与导出
- 在线实时预览照片 + 信息边框合成效果
- 支持 4 种排版方向：**下边 / 上边 / 左边 / 右边**
- 支持文字水平对齐（左 / 居中 / 右）与垂直对齐（左右排版时）
- 支持焦距 + 光圈 + 快门 + ISO 合并为一行参数
- 可调节**边框宽度**和**内容大小**
- 6 种背景配色 + 5 种文字配色，支持深色风格
- 导出为高质量 PNG 图片

## 🚀 使用方法

无需安装，直接在浏览器打开即可使用：

页面按「读取 → 选择 → 导出」三步组织：

1. **照片信息**：将照片拖入上传区或点击选择，自动读取机型、镜头、光圈 / 快门 / ISO / 焦距、时间与位置；可展开「全部 EXIF 字段」并搜索
2. **选择输出内容**：在「显示字段」中勾选并拖动排序（同时作用于文本和相框），切换「详细 / 简约」格式后一键复制
3. **生成相框**：按「布局 / 文字 / 边框」分组调整参数，实时预览后点击「下载相框图片」导出 PNG

随时可点击右上角「更换图片」或直接拖入新照片。

## 🛠️ 技术栈

| 技术 | 用途 |
|------|------|
| 纯 HTML / CSS / JavaScript | 零依赖前端实现 |
| [exif-js](https://github.com/exif-js/exif-js) | EXIF 数据解析 |
| [SortableJS](https://sortablejs.github.io/Sortable/) | 拖拽排序 |
| [BigDataCloud API](https://www.bigdatacloud.com/) | GPS 反向地理编码（主） |
| [OpenStreetMap Nominatim](https://nominatim.org/) | GPS 反向地理编码（备用） |
| HTML5 Canvas | 相框图片合成与导出 |

---

## 🔒 隐私说明

- **图片文件仅在本地浏览器内处理**，不上传任何服务器
- 仅在照片包含 GPS 信息时，会向第三方地理编码 API 发送坐标（纬度/经度）以换取地名，不含图片内容
- 无 Cookie，无追踪，无登录
